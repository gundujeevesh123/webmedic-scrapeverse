The self-heal loop

Three deterministic stages. Zero silent failures.

Every scraper run flows through the same three stages. Nothing is promoted without evidence.

01 / DETECT

Health score collapses

8 deterministic rules score every record — required fields, types, plausible values, URL validity, semantic anomalies. A single number in [0, 1] with three status buckets. Cosmetic HTML changes never trigger alarms; only real data degradation does.

02 / REPAIR

Candidates generated, tested, scored

Six candidate sources per broken field: stable attributes, class synonyms, tag+role heuristics, text anchors, positional fallbacks, historical winners. Each candidate is executed against the actual HTML and scored: 0.25·Schema + 0.25·Completeness + 0.20·Type + 0.15·Similarity + 0.15·Historical.

03 / DEPLOY

Gated promotion, versioned rollback

Three-tier gate: reject / shadow / promote. Even a high-scoring candidate must pass a shadow run before it reaches production. Every strategy is versioned in SQLite. Rollback is one database write, fully audited in repair_events.
